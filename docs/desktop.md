# Keco Studio Desktop App

Download the Windows installer or the DMG matching your Mac from GitHub Releases.
Windows users can save the `.exe` to their Desktop. SmartScreen may warn because
the installer is unsigned. macOS builds are ad-hoc signed but not notarized, so
use Finder Open or Privacy & Security's Open Anyway control. Desktop sign-in is
email/password only; Google login remains in the browser. The app is online-only
and intentionally blocks external links and popup windows in this first release.
